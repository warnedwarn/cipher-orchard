# README Design Contract

## readmeArchetype
Lab notebook.

## readmeNarrativeVoice
Curious cryptobotanist documenting a live semantic specimen.

## readmeSectionPattern
Specimen entry, growth law, graft protocol, validator notes, cultivation commands, field cautions.

## readmeMotif
Pressed plant research notebook.

## requiredFactsPlacement
Identity and links sit on the specimen label. State and methods are described as growth law. Consensus and backstops are validator notes. Setup and tests are cultivation commands. Limitations are field cautions.

## bannedReadmePatterns
No operational dispatch, map legend, software manual, feature list, badge row, or standard open-source section order.

## proofOfDifference
The previous README uses terse emergency doctrine. This one uses research observations, botanical labels, and cultivation commands with a different opening, section order, and technical metaphor.
